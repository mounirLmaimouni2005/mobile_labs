
# Destination Guide
## Technical Project Presentation

*Destination Guide*  is a web application designed to help visitors discover tourist destinations in Morocco.

---
## 1.Project Topic

The **Destination Guide** project consists of developing a web platform dedicated to discovering tourist destinations in Morocco.

The platform allows visitors to explore different destinations, read their descriptions, and discover the regions where they are located.

The website content is managed by a single *Tour Guide*, who is responsible for publishing and managing tourist destinations.

---
## 2. Project Objective

The main objective of this project is to make discovering tourist destinations easier by providing a simple and accessible web platform.

It also aims to help the Tour Guide manage website content efficiently.

---
## Specific Objectives

- Present different tourist destinations.

- Provide useful information about each destination.

- Organize destinations by region.

- Allow the Tour Guide to add new destinations.

- Allow the Tour Guide to update existing destinations.

- Allow the Tour Guide to delete destinations.

- Provide a simple and responsive user interface.

---
## 3. Project Functionality
  The application has two main actors:

### 3.1 Tour Guide
The Tour Guide is the website owner and content manager.

**The Tour Guide can:**
- Log in to a private account.

- View all destinations.

- Add a new destination.

- Update destination information.

- Delete existing destinations.

- Manage website content.

---
### 3.2 Visitor
A visitor can explore the website without creating an account.

**Visitors can:** 
- Browse tourist destinations.

- Read destination descriptions.

- Explore different regions.

- Discover tourist information.
