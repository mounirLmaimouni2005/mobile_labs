# Scrum Lab

## 1. Lab Overview

This lab is about discovering and understanding **Scrum**, an Agile framework used to organize teamwork and manage projects.

The goal is to learn the Scrum framework, understand its main concepts, and prepare for applying them to the Technical Project.

This lab is divided into two main phases:

- **Phase 1 — Learning:** Understand Scrum through a structured presentation.
- **Phase 2 — Practice:** Apply Scrum concepts to organize the Technical Project and prepare the first Product Backlog.

## 2. Lab Objectives

By the end of this lab, the learner should be able to:

- Understand the definition, origin, and objectives of Scrum.
- Understand the problems Scrum helps address.
- Identify Scrum's fundamental principles.
- Understand the responsibilities of each Scrum accountability.
- Identify Scrum events and artifacts.
- Understand how a Sprint works.
- Apply Scrum concepts to a real development project.

## 3. Presentation Plan

The presentation must follow this exact structure:

1. Page de garde
2. Introduction générale
3. Définition de Scrum
4. Problématique et solution
5. Les fondamentaux de Scrum
6. Les composants de Scrum
7. Fonctionnement et conclusion

## 4. Required Concepts

The presentation must explain the following concepts:

### Scrum Fundamentals

- Agile methodology and Scrum.
- Scrum pillars: Transparency, Inspection, Adaptation.
- Scrum values: Commitment, Focus, Openness, Respect, Courage.

### Scrum Accountabilities

- Product Owner.
- Scrum Master.
- Developers.

### Scrum Events

- Sprint.
- Sprint Planning.
- Daily Scrum.
- Sprint Review.
- Sprint Retrospective.

### Scrum Artifacts

- Product Backlog.
- Sprint Backlog.
- Increment.

### Scrum Commitments

- Product Goal.
- Sprint Goal.
- Definition of Done.

## 5. Practical Phase

After understanding the theoretical concepts, apply Scrum to the Technical Project.

The practical work must include:

- Identifying the Product Owner.
- Identifying the Scrum Master.
- Understanding the responsibilities of the team.
- Organizing the project starting phase.
- Identifying project needs and priorities.
- Preparing the first Product Backlog.
- Understanding how to organize Daily Stand-up meetings.

## 7. Presentation Requirements

The presentation must be:

- Written in French.
- Created using Markdown and Marp.
- Professional, modern, and easy to read.
- Designed in 16:9 format.
- Limited to a maximum of 10 slides.
- Focused on one main idea per slide.
- Supported by clear examples and useful diagrams.
- Provided with concise speaker notes.

The presentation should prioritize understanding over memorization.
