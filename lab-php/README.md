# PHP Lab Assignment

## Objective
This lab allows you to study and put into practice three PHP concepts that have not yet been covered in class:
- **Error and Exception Handling:** Detecting and handling abnormal situations.
- **Namespaces:** Organizing classes and avoiding naming conflicts.
- **Traits:** Sharing methods across multiple classes and reducing code duplication.

For each concept, explain its role and implement a practical example related to the project and its architecture.

---

## Required Work
1. **Research & Concepts:** Research the three concepts and explain their core principles.
2. **Practical Examples:** Create a practical example for each within the context of the project.
3. **Verification & Integration:** Verify the examples and explain how they integrate into the architecture.
4. **Presentation:** Present the results in `presentation.md` using the Marp format.

> **Note:** The examples, commands, and versions must match the project's actual environment.
